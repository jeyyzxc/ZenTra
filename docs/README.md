# Zion Documentation

Project documentation is organized here so the application root stays focused on runtime source and configuration.

## Folders

- `plans/` - implementation plans, specifications, and architecture notes.
- `n8n/` - production n8n orchestration documentation.
- `archived-prompts/` - historical prompts and temporary planning artifacts kept for traceability.
- `design-assets.md` - policy and notes for design mockups, screenshots, and runtime assets.

Root-level `README.md`, `AGENTS.md`, and `CLAUDE.md` remain at the project root because external tools expect them there.
